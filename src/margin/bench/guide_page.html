    Use your own bug

    Margin judges a fix by tests. A task names the repository, the commit before the fix, the issue text, the tests that should flip from failing to passing, and the known fix commit, which is how Margin checks the task is valid.

    {{task_toml}}
    uv run margin tasks validate --tasks-file my-tasks.toml
uv run margin quote --task cachetools-423 --tasks-file my-tasks.toml
uv run margin run --task cachetools-423 --arm E --tasks-file my-tasks.toml
    Not yet: a new bug with no fix and no tests. There is no margin fix <issue-url> command, hosted app or API.
